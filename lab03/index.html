Lab 2 Reflection: In this module, we learned all about HTML; we learned the meaning of it and why it is important when it comes to web browsing. The Hypertext Markup Language uses markup to describe the structure of web pages, and this structure is made up of tags that label the pieces of content. In this module, I started off having a hard time correcting mistakes on the validation website. Following your directions to type out the code instead of copying and pasting helped in the long run because I made my mistakes on the practice classwork activities, which allowed me to breeze through the lab02 assignment. In conclusion, I learned many new things, such as placing an external link in our webpages and numbering different headings, and I look forward to learning more.

Lab 3 Reflection: This week in Lab 3 we learned how to code with basic CSS. For me this module was very difficult but satisfying.We learned that CSS means Cascading Style Sheet and this is the indentity of a HTML page. This controls things such as text colors and the size of the text. Also we learned the difference between ID and Class selectors, these come in handy when trying to alter a specific area or multiple different areas on a HTML page. The ID and class selectors were the most difficult part for me, it took a long time to figure out but when I did it felt very rewarding.
